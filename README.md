# 🛒 Blinkit Sales Analysis | End-to-End Data Analytics Project

## 📌 Project Overview

This project demonstrates an end-to-end Data Analytics workflow using Microsoft Excel, SQL, and Power BI. The goal was to analyze Blinkit's sales data, uncover meaningful business insights, and build an interactive dashboard to support data-driven decision-making.

The project covers the complete analytics lifecycle, including data preparation, SQL-based business analysis, and interactive dashboard development.

---

# 🎯 Business Objective

The objective of this project is to analyze Blinkit's sales performance by identifying trends in product categories, outlet performance, sales distribution, and customer preferences through an interactive business dashboard.

# 💡 Key Business Insights

- Fruits & Vegetables generated the highest sales.
- Tier 3 outlets contributed significantly to total revenue.
- Medium-sized outlets showed strong sales performance.
- Sales varied across different outlet establishment years.
- Product categories contributed differently to overall business growth.
- The dashboard enables users to explore sales performance interactively using filters.
